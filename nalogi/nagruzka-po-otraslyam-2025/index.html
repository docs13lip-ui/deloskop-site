Налоговая нагрузка и рентабельность по отраслям за 2025 год

Данные ФНС от 05.05.2026 · сверено 02.10.2026 · следующее обновление — май 2027
КороткоСредняя налоговая нагрузка по России за 2025 год — 11,9% (за 2024-й — 11,6%), рентабельность продаж — 10,9%, активов — 5,0%. Это средние значения, а не порог: ФНС сравнивает с ними компании как с одним из 12 признаков при отборе на выездную проверку. Сравнить свою нагрузку с отраслью — бесплатно, в браузере.

Как пользоваться таблицей

  • Найдите свою строку по основному ОКВЭД. ФНС даёт нормы по разделам и части групп: для кода 46.90 — строка «торговля оптовая», для 41.20 — раздел F «Строительство». Если вашего раздела в таблице нагрузки нет (например, раздела M), нормы ФНС для него нет — со строкой «Всего» себя не сравнивайте.
  • Нагрузка = налоги / доходы. В норме ФНС учтён НДФЛ за работников, страховые взносы не учтены. Свою нагрузку для сравнения считайте так же — или в калькуляторе.
  • Упрощёнка. Нормы посчитаны по всем организациям, с НДС и налогом на прибыль. Для упрощенца сравнение некорректно.
  • Регионы. Нормы нагрузки ФНС публикует только по России в целом — региональных норм нет.
  • Рентабельность. Признак отбора — рентабельность по бухучёту ниже среднеотраслевой на 10% и более (критерий 11 приложения 2 к Концепции).

Частые вопросы

Какая средняя налоговая нагрузка по России за 2025 год?

Средняя налоговая нагрузка по России за 2025 год — 11,9% (за 2024-й — 11,6%), рентабельность продаж — 10,9%, активов — 5,0%.

Средняя нагрузка по отрасли — это порог для налоговой?

Это средние значения, а не порог: ФНС сравнивает с ними компании как с одним из 12 признаков при отборе на выездную проверку.

Как найти норму нагрузки для своего ОКВЭД?

Найдите свою строку по основному ОКВЭД. ФНС даёт нормы по разделам и части групп: для кода 46.90 — строка «торговля оптовая», для 41.20 — раздел F «Строительство».

Что делать, если моего вида деятельности нет в таблице?

Если вашего раздела в таблице нагрузки нет (например, раздела M), нормы ФНС для него нет — со строкой «Всего» себя не сравнивайте.

Входят ли НДФЛ и страховые взносы в норму нагрузки?

Нагрузка = налоги / доходы. В норме ФНС учтён НДФЛ за работников, страховые взносы не учтены.

Подходят ли эти нормы для упрощёнки?

Нормы посчитаны по всем организациям, с НДС и налогом на прибыль. Для упрощенца сравнение некорректно.

Есть ли нормы нагрузки по регионам?

Нормы нагрузки ФНС публикует только по России в целом — региональных норм нет.

Какая рентабельность привлекает внимание налоговой?

Признак отбора — рентабельность по бухучёту ниже среднеотраслевой на 10% и более (критерий 11 приложения 2 к Концепции).

Проверьте поставщика до оплаты

Введите ИНН — покажем, что известно о компании, с источником и датой, и что запросить у поставщика перед оплатой. Бесплатно.
